# Scraping service (Python + FastAPI)

Not a pnpm workspace package. `pnpm lint` and `pnpm typecheck` do not cover it —
verify by running the service, per `scraping/README.md`.

Never read or edit `scraping/.venv/`.

## Adding a crawler

One module per site, named `app/parser.<name>.py`, then add `<name>` to
`CRAWLER_NAMES` in `app/parsers.py`. The docstring at the top of `parsers.py` lists
the functions the module must expose — follow it rather than copying a parser whole.

The dotted filename is deliberate and matches the repository's `<kind>.<name>`
naming, which is why `parsers.py` loads these by path instead of by import.
