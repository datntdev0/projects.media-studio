# Frontend (Nuxt 4 + Nuxt UI 4 + Tailwind 4)

## Components (DO NOT VIOLATE)

- Do not break a component open tag into multiple lines if it is not too long.
- Do not write a `<style>` tag in the Nuxt component. Use the CSS file or tailwind classes.
- Prefer to use the tailwind classes instead of writing custom CSS.

Components live flat in `app/components/`, prefixed `App`. Composables are
`use*.ts` in `app/composables/`.

## Reaching the API (DO NOT VIOLATE)

- Reach the API only through `useApiClient()` (`authClient`, `libraryClient`, `scrapingClient`).
- Do not add a hand-written `$fetch` wrapper beside it.
- Do not hand-edit `app/utils/api.clients.ts`. It is NSwag's output — change the
  backend DTO and rerun `pnpm generate:api`.

A raw `fetch` is only for Firebase Storage download URLs, which are not the API.

## Styling

The design system is in `app/assets/css/` — see `DESIGN.md`. Read the roles in
`tokens.css`, never the raw primitives. Tailwind only reads `@theme` from the entry
stylesheet, so those blocks must stay in `main.css`.
