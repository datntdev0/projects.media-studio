# Coding Style (DO NOT VIOLATE)

- Do not write too long comments inside the code.
- Do not write too complex code. Keep it simple and readable.
- Do not write import in multiple lines. Use single line import.
- Do not break the line if the line is not too long. Keep it in a single line.
- Do not write duplicate code. Consider refactoring it into a function or a class.

## Comments

One line is the norm. A block comment must earn itself by saying something the
code cannot — never restate the code, and never argue for the design.

## Before you finish

- `pnpm lint` and `pnpm lint:fix` to check and fix the linting issues.
- `pnpm typecheck` to ensure TypeScript types are correct.

Both cover `backend` and `frontend` only. `scraping` is not in the pnpm workspace.
